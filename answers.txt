/******************************************************************************
** 1. Describe how your firstIndexOf() method in RangeBinarySearch.java
**    finds the first index of a key that equals the search key.
******************************************************************************/

The function utilizes the binary search algorithm for the relevant dictionary to find the given prefix.
The loop runs continuously for smaller and smaller array sizes until only one copy of the prefix remains, and that is the first index.


/******************************************************************************
** 2. What is the worst case time complexity in the number of compares
**    that each of the operations in the Autocomplete data type make,
**    as a function of the number of terms n and the number of matching terms m?
******************************************************************************/

sortDictionary():  O(nlogn)
    It sorts all n terms by lexicographic order, which runs once in the constructor.

allMatches():  O(logn + mlogm)
    It uses two binary searches to find the matching range, which uses O(logn).
It then sorts the m matches by weight which uses O(mlogm). 

numberOfMatches():  O(logn)
    Uses two binary searches to find the first and last matches and calculates the count from those indices which requires no additional comparisons.
